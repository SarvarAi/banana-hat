# Banana Hat

A self-hostable hackathon submission and judging platform, being built for
[DOGFOOD 2026](https://dogfoodhack.com).

Work in progress. The plan: submissions with a deadline that holds, judging with
backend-enforced isolation and documented normalization, a public gallery and
community vote, and everything auditable.

```
docker compose up
```

Then open http://localhost:8080. Apache-2.0.
