Export

Everything leaves in open formats. event.json is the DOGFOOD fixture format plus rubric weights, prizes and pending assignments: import it into another Banana Hat, or any portal that reads fixtures.json.

  • event.json the whole event, re-importable
  • scores.csv one row per review
  • results.csv ranking under {{ event.get_normalization_display }}
  • projects.csv including drafts and duplicates
  • audit.csv the audit trail

Import

New events can be created from a fixture-format file on the import page, or with POST /api/v1/events/import.
